
# Day 31 Internship Project: Responsive Developer Portfolio Website

## 1. Project Overview

The Responsive Developer Portfolio Website is a personal website developed using HTML5, CSS3, and JavaScript. It presents a developer's profile, technical skills, projects, education, internship experience, and contact information in a professional and visually attractive layout.

The website uses a modern dark theme with gradient colors, animated elements, project cards, skill progress bars, and responsive navigation. It is designed to work across desktop computers, tablets, and mobile devices.

## 9. Working Procedure

### Step 1: HTML Structure

Semantic HTML elements such as header, nav, main, section, article, form, and footer organize the page content.

### Step 2: Styling and Layout

CSS variables maintain consistent colors and spacing. Flexbox and Grid organize the page sections, while media queries adjust layouts for smaller screens.

### Step 3: Visual Design

Gradients, CSS shapes, borders, and shadows create the dark portfolio theme. Keyframe animations add movement to the profile card and floating badges.

### Step 4: Responsive Navigation

JavaScript opens and closes the mobile navigation menu. Clicking a navigation link closes the menu automatically.

### Step 5: Scroll Animations

IntersectionObserver detects when content enters the viewport and reveals elements. It also triggers the skill progress bars.

### Step 6: Form Validation

JavaScript checks the name, email address, subject, and message before preparing an email link.

### Step 7: Testing

The website is checked across screen sizes and the navigation, animations, links, and form validation are tested.

## 11. Limitations

- The portfolio is a frontend-only project.
- The contact form does not directly send or store messages.
- The skill percentages are illustrative self-assessments.
- Project inquiry links open an email application rather than a live project demo.
- The Google Fonts import requires internet access for the selected fonts.
- The project does not include a backend, login system, or database.
